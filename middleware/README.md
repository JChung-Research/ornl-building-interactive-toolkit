# ORBIT — Middleware

The distributed agent layer of the **ORBIT** platform — it connects building equipment to the web application and the time-series historian. See the [root README](../README.md) for the overall architecture.

## Overview

The middleware runs a set of agents that move data between the building and the rest of ORBIT. For each device or data source, an **Interface/Recv agent pair** polls the source — a device server ([`../device-servers/`](../device-servers/)) or a BOPTEST simulation — publishes structured sensor data to a topic, and forwards it to the **UI gateway**, which persists it to InfluxDB and serves the web app. Control signals flow back along the same path.

## Components

- **agents** ([`agents/`](agents/)):
  - **InterfaceAgent** — polls a backend (a device server or BOPTEST), packages sensor data + metadata, and publishes to a topic.
  - **RecvAgent** — subscribes to topics, invokes a dynamically loaded controller, and forwards readings to the UI gateway (returning control signals).
  - **WeatherAgent** — publishes outdoor weather to a topic.
- **Controllers** ([`init/`](init/)) — per-device modules the agents load dynamically by config (`ecobee_init`, `modbus_init`, `schneider_init`, `egauge_init`, `boptest_building_init`, `weather_init`, …), plus `ui_init` (the RecvAgent → UI-gateway callback).
- **UI gateway** ([`init/ui_gateway.py`](init/ui_gateway.py)) — a Flask server bridging the agents (port 5100) and the web app (port 8443), with InfluxDB historian writes.
- **Configs & scripts** — agent configs in [`agent_config/`](agent_config/) (site-specific; generated by the [configuration converter](../configuration-converter/)), agent install/upgrade scripts in [`scripts/`](scripts/), middleware config in [`middleware_config/`](middleware_config/).

## Services

`docker-compose.yml` defines three services:

| Service | Build | Role |
|---------|-------|------|
| `middleware` | `Dockerfile` | VOLTTRON platform + agents; `start.sh` starts the platform and installs the configured Interface/Recv pairs |
| `ui` | `Dockerfile.ui` (`orbit-ui`) | the UI gateway |
| `influxdb` | `influxdb:1.8` | short-term time-series historian |

By default `start.sh` enables the **ecobee** and **modbus** agent pairs;
eGauge, Schneider, and weather are present but commented out — edit the `upgrade_*`
lines in `start.sh` to change the active set.

## Run

The whole platform normally runs as one Compose project from the repository root
(`docker compose up -d`). To build/run just the middleware:

```bash
cd middleware
docker compose build
docker compose up -d
```

### Run the UI gateway / a fake device server directly (dev)

```bash
python init/ui_gateway.py --certfile [path-to-certfile] --keyfile [path-to-keyfile]
python ../device-servers/server_fake_BOPTEST.py
```

> The UI gateway needs a valid TLS certificate + key for HTTPS. Update any device IP
> addresses in the configs/scripts to match your local network.
